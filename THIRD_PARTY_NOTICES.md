# Third-party runtime notice

This test archive contains plugin source and installation scripts. It does not include a DSH or Electron binary distribution.

During installation the scripts copy runtime files from the recipient's existing DeepSeek Harness installation into a dedicated local plugin data directory. The original installation is not modified. Available `LICENSE.electron.txt` and `LICENSES.chromium.html` files are copied with that runtime. Other notices in the original DSH installation remain applicable to its components.

This package uses the Windows PowerShell, .NET, Win32 and DWM facilities already present on the recipient's computer.
